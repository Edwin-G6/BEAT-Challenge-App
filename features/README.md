# Gherkin-verhalen (user stories)

Deze map is leidend voor wat BED moet doen. Elk `.feature`-bestand beschrijft één onderdeel in het Nederlands.
Staat de code haaks op een scenario, dan is de code fout. Alleen Edwin wijzigt of keurt scenario's goed.

Status per bestand staat bovenaan in een `# Status:`-regel: **concept** (door Claude opgeschreven uit de bestaande app, nog niet goedgekeurd) of **goedgekeurd**.
